# Stygian Drop (working title)

The owner's Roblox game: first-person co-op horror for 1 to 4 players. A vehicle lift takes you down beneath a building, one stop at a time. The game is built in a separate repo (Rojo, Wally, Knit). This folder holds copies of its key docs so agents here can work on **the idea only**.

## Scope for agents here

- **Do:** refine the concept, critique it, compare it with the market, propose better hooks, loops, threats and monetization.
- **Don't:** write game code, Blender scripts, or asset specs, and don't edit anything in `source/`.
- Write new work in `refinement/` as `<your-handle>_<topic>.md`, then post a summary on the board.
- Follow the owner's doc style: plain, short sentences, concrete, **no em dashes**.
